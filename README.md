# Stars Partners — главное меню

Копия главного меню партнёрского бота с переделанной вёрсткой и
раскладкой кнопок. Работает как самостоятельный бот: `/start` —
карточка меню, шесть разделов, навигация внутри одного сообщения.

## Запуск

```
pip install -r requirements.txt
copy .env.example .env   # и вписать BOT_TOKEN
python main.py
```

Посмотреть, как лягут карточки, можно без токена и без Telegram:

```
python preview.py
```

Скрипт печатает все экраны с кнопками и заодно проверяет парность
HTML-тегов — незакрытый `<b>` в Telegram роняет отправку целиком.

## Что изменилось против оригинала

**Текст.** Было полотно из восьми строк, где уровень, комиссия, остаток
до следующего уровня и четыре служебные ссылки шли одним списком —
одинаково важные, читать приходится всё. Стало три слоя:

- уровень, комиссия и прогресс — в цитате, отдельным блоком;
- деньги, боты, рефералы — одной строкой цифр под ней;
- служебные ссылки — в раскрывающейся цитате: свёрнуты, но на месте.

Добавлена полоса прогресса до следующего уровня: «осталось 967.47 ₽»
само по себе ни о чём не говорит — непонятно, это начало пути или
почти финиш.

**Кнопки.** Было шесть рядов по одной — столбик одинаковых полос на
весь экран. Стало пять рядов с парами по смыслу, частое действие
(«Личный кабинет») — первым слева. «Поддержка» вынесена кнопкой-ссылкой:
нажатие открывает диалог сразу.

**Состав.** «О Lucky Buy» убран, «Субпартнёрка» заменена на «Подписка».

## Файлы

| Файл | Что внутри |
|---|---|
| `main.py` | запуск, команды, поллинг |
| `handlers.py` | навигация: один экран, который перерисовывается на месте |
| `keyboards.py` | раскладка кнопок, реестр экранов `SCREENS` |
| `texts.py` | карточки всех экранов, вёрстка |
| `partners.py` | партнёр и лестница уровней |
| `config.py` | токен, ссылки, тарифы, баннер |
| `preview.py` | предпросмотр карточек в терминале |

## Что нужно доделать под себя

`partners.py` — заглушка: данные живут в памяти и обнуляются при
перезапуске, новый партнёр заводится с демо-цифрами со скриншота.
Подключая свою базу, оставьте сигнатуру `get(uid, name) -> Partner` —
всё остальное ходит за данными только через неё.

Кнопки `a:*` (вывод, история, реферальная ссылка, добавление бота,
оплата тарифа) отвечают всплывашками-заглушками из словаря `ACTIONS`
в `handlers.py`.

Баннер над меню: положите картинку в `assets/menu.png` или укажите
`MENU_PHOTO` в `.env` (file_id уже загруженной картинки — выгоднее
всего, Telegram не перезаливает файл на каждое открытие меню). Без
картинки меню показывается обычным сообщением.
